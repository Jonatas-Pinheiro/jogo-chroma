# Chroma — versão com todos os arquivos na raiz

Esta versão foi achatada para upload direto no GitHub, sem subpastas.

## Estrutura

Todos os arquivos ficam no mesmo nível:

```text
index.html
style.css
firebase-auth.js
01-config.js ... 09-admin.js
BAU-*.png
PRATA.png, AMETISTA.png, OURO.png, DIAMANTE.png, DOMINADOR.png, SOBERANO.png
CONQUISTA-*.png
*.mp3
*.png
```

Não crie ou restaure as pastas `css`, `js` ou `assets` ao fazer o upload desta versão.

## GitHub Pages

1. Envie todos os arquivos desta pasta para a raiz do repositório.
2. Em **Settings → Pages**, escolha a branch principal e a pasta `/ (root)`.
3. Abra a URL gerada pelo GitHub Pages.

O `.nojekyll` já está incluído.
